Headline results

Base calling

Guppy 6.0.1 (DNA) · Dorado 0.5.3 (RNA)

Best match rates of 93.60% on NA12878 and 93.96% on hek293t_wt. Second-generation sequencing reaches 99.9%, so the headroom is large.

PolyA detection

Tailfindr 1.4

Highest detection rate on all seven test datasets; Nanopolish polya varies strongly across datasets because it depends on alignment. Length estimates are similar across tools.

Segmentation & alignment

SegPore 1.0

Lowest average within-event std and highest log-likelihood against the ONT k-mer table on all three human RNA test sets.

Modification detection

m6Anet (m6A) · CHEUI-solo (m5C)

m6Anet leads on all three m6A ground truths (ROC AUC up to 0.891); CHEUI-solo leads for m5C (ROC AUC 0.842). Precision-recall AUCs stay below 0.5, showing how hard the task remains.

How the benchmarks were run

  • Held-out test data. Test datasets were selected at random and none was used to train any baseline model.
  • Same preprocessing for every method. All inputs come from the unified pipeline, so differences reflect the methods rather than the data preparation.
  • Evaluation code is open. Dataloaders and metric implementations live in the NanoBaseLib package; the base calling metrics use the parasail pairwise aligner.
  • Subset of datasets. The paper's experiments use a subset of the 16 datasets to demonstrate the framework; the remaining datasets are available for broader evaluations.

Submitting a method

NanoBaseLib v1.0 does not run a hosted leaderboard. To add a method, evaluate it with the package's scripts on the test datasets listed on each task page and open an issue or pull request with the output files and the exact command line. Results are added to the task pages with the method name, version and configuration.
